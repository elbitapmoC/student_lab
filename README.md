# Coding-focused student lab

Use Node 24.x or a supported Node 22 release at least 22.12.

npm ci
npm run dev

Open http://127.0.0.1:3000. After Task 2 creates server/index.ts,
run npm run api in another terminal. Both terminals use this folder.

Use browser interactions/curl to inspect behavior. npm run typecheck
checks TypeScript; npm run build checks the production build.

This folder contains configuration, a blank page, CSS and invented JSON.
There are no automated testing dependencies, configurations or exercises.
Database work remains deferred. Existing feature code from v3 can continue;
you do not need to restart just to use this revised workbook.
